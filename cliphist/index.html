功能

不只是保存，而是更快地再次使用。

ClipHist 把剪贴板历史变成一个可以搜索、分类、键盘直达的工作空间。

复制即记录

实时监听剪贴板变化，自动记录文本、富文本、图片与文件列表，不打断当前工作。

输入即找到

即时搜索与分类筛选，历史再多也能迅速收敛。

手不离键盘

全局快捷键呼出或隐藏窗口。↑ / ↓ 导航，Enter 复制，1–9 快捷粘贴对应记录。

历史只属于你

数据保存在本机，采用本地 JSON 持久化，图片外置存储。检查更新时仅访问 GitHub Releases。

快捷键

呼出之后，三步完成粘贴。

默认使用 Ctrl+Shift+V 呼出窗口（可在设置中修改）。也可开启游戏模式，临时暂停双击修饰键唤醒。

01 呼出

使用全局快捷键随时打开窗口。

02 定位

直接输入关键词，或使用 ↑ / ↓ 导航。

03 使用

Enter 复制选中项，数字键 1–9 快速粘贴对应记录，Esc 取消搜索或关闭窗口。

平台

熟悉的体验，带到每台电脑。

  • Windows：安装包 .exe 或 .msix
  • macOS（Apple Silicon）：.dmg
  • Linux：.deb，或 Arch 软件包 my-cliphist
  • 桌面端使用 Flutter + Rust 构建
