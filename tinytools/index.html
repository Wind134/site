功能

少切几个窗口，多掌握一点系统状态。

为开发、运维和日常排障准备的常用能力，不堆功能，只解决高频问题。

稳定管理多个 SSH 隧道

集中创建、编辑、批量启停反向隧道；支持密码与 OpenSSH 私钥认证。首次连接显示 Host Key 指纹，已信任密钥发生变化时会阻止连接。网络波动后自动尝试重连，状态和日志在应用内持续更新。

端口被谁占用，一眼看清

查看 IPv4 / IPv6 TCP 监听端口与已建立连接，按连接类型、协议、端口、PID、进程名或地址即时筛选。可自动刷新，并可隐藏系统内核记录。

删不掉的文件夹，找到真正占用者

直接拖入文件或文件夹，也可以使用原生选择器或输入路径。递归查询被占用的文件，显示进程、应用名、启动时间和路径。大目录扫描可随时取消。

Windows 11 原生体验

使用 WinUI 3 / Windows App SDK 构建，支持浅色、深色和跟随系统主题，以及系统托盘、单实例运行和关闭到托盘。unpackaged、self-contained、单文件发布，目标电脑无需预装 .NET。

安全

敏感配置，应该留在你的电脑里。

TinyTools 不需要账户，也不会上传隧道配置、进程列表或文件路径。更新检查只访问公开的 GitHub Releases API。主机地址与密码使用 Windows DPAPI 加密，并绑定当前 Windows 用户；私钥只记录路径，不复制密钥文件。

  • 01
    Host Key 校验首次确认指纹，后续连接自动核验，降低中间人攻击风险。
  • 02
    原子配置保存写入前保留备份，通过临时文件替换，减少配置损坏风险。
  • 03
    关键进程保护PID 0/4 禁止终止；关键 Windows 进程会显示明确的高风险确认，避免误操作。

系统要求

下载即用。

  • Windows 10 x64 或 Windows 11 x64（最低 Windows 10 build 17763）
  • 自包含发布，无需预装 .NET
  • SSH 功能需要能够访问 SSH Server
  • 查看或终止受保护进程时可能需要管理员权限
