01 · Windows

MailClient

免费开源的 WinUI 3 桌面邮件客户端。在自己的电脑上阅读、搜索、撰写并发送 Gmail、Outlook 与 IMAP 邮件，没有开发者后台，也不上报使用数据。

  • 支持 Gmail、Outlook / Microsoft 365，以及 QQ、163、126 和其他 IMAP
  • 三栏界面：账户与文件夹、邮件列表、阅读窗格
  • 本地搜索、草稿自动保存，已读与星标双向同步
  • 邮件缓存在本机，凭据使用 Windows DPAPI 加密

02 · Windows · macOS · Linux

ClipHist

轻量、快速的跨平台剪贴板历史管理器（My ClipHist）。复制过的文字、富文本、图片与文件列表都会被记住，需要时一键呼出、即时搜索。

  • 实时监听剪贴板，自动记录文本、富文本、图片与文件列表
  • 即时搜索与分类筛选，支持 1–9 快捷粘贴
  • 全局快捷键呼出窗口，支持键盘导航
  • 剪贴板数据完全保留在本地，检查更新仅访问 GitHub Releases
Flutter + Rustv2.2.0开源

03 · Windows

TinyTools

为 Windows 11 重新设计的轻量桌面工具箱，把 SSH 隧道、端口与进程查看、文件或文件夹占用定位收进同一个原生应用。

  • 创建、编辑并批量启停 SSH 反向隧道，支持断线自动重连
  • 查看端口与进程，按端口、PID 或进程名筛选
  • 拖入文件或文件夹，定位真正的占用进程
  • 主机地址与密码由 Windows DPAPI 加密，配置留在本地
