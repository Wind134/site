MailClient

免费开源的 WinUI 3 桌面邮件客户端。在自己的电脑上阅读、搜索、撰写并发送邮件，没有开发者后台，也不上报使用数据。

功能

三栏布局，账户、列表与阅读各得其所。

主界面按账户与文件夹组织邮件，支持撰写、回复、搜索和系统通知。

多种邮箱，一个入口

添加账号向导支持 Gmail、Outlook / Microsoft 365、QQ、163 / 126 以及其他 IMAP / SMTP。Gmail 使用 OAuth 2.0（回环重定向 + PKCE），Outlook 使用 MSAL 与 Microsoft Graph，通用 IMAP 由 MailKit 接入。

本地搜索与草稿

在当前文件夹、当前账号或全部邮箱中搜索，支持 from:、subject:、is:unread 等运算符。草稿每 3 秒自动保存到本地，可继续编辑后发送。

双向同步

已读、星标、移动和删除会写回服务器；网页或手机上的变更也会同步回来。收件箱支持 IMAP IDLE，也可定时轮询。

发送与通知

撰写窗口支持回复、全部回复与转发，附件和 HTML 正文可本地预览。新的未读收件箱邮件会弹出 Windows 通知，点击即可打开。

关闭后仍可在托盘运行

关闭主窗口默认保留在通知区域后台运行。设置里也可以检查来自 GitHub Releases 的更新。

隐私

邮件留在你的电脑里。

MailClient 是本地桌面客户端，不收集、不上报用户数据。检查更新只访问 GitHub Releases 的公开接口。

  • 01
    凭据加密保存账号密码保存在 DPAPI 加密的凭据文件中，绑定当前 Windows 用户。
  • 02
    本地邮件库邮件与文件夹缓存在本机 SQLite 数据库中，卸载时默认保留，便于重装后继续使用。
  • 03
    政策可公开查阅完整说明见项目主页上的隐私权政策。

系统要求

64 位 Windows 即可使用。

  • Windows 10 1809 及以上，或 Windows 11
  • 仅支持 64 位系统
  • 安装包为自包含发布，不必另外安装 .NET 或 Windows App Runtime
  • 只为当前用户安装，不需要管理员权限
